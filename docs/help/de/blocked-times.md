# Sperrzeiten

Urlaub, Wartung oder Feiertage tragen Sie als gewöhnliche Buchung mit einem blockierenden Status ein. Eine eigene Verwaltung für Sperrzeiten gibt es nicht und braucht es nicht.

## Zeitraum sperren

1. Klicken Sie in der Objektliste beim Objekt auf **Buchungen**.
2. Tragen Sie den Zeitraum ein.
3. Wählen Sie den Status **gesperrt**.
4. Tragen Sie unter **Interne Notiz** bei Bedarf den Grund ein. Klicken Sie auf **Speichern**.

Der Status „gesperrt“ zeigt auf der Website nur „belegt“, aber keinen Grund. Eine öffentliche Beschriftung erscheint bei ihm nicht.

## Mehrere Objekte sperren

Sperrzeiten gelten je Objekt. Sollen mehrere Objekte gesperrt sein, legen Sie die Buchung für jedes einzeln an.

> [!NOTE]
> Regelmäßig geschlossene Zeiten wie Wochenenden oder Mittagspausen gehören nicht hierher. Dafür gibt es im Modus Zeitraum die [Öffnungszeiten](opening-hours.md).
