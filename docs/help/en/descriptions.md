# Object descriptions

Reservations only manages the name and rules of an object. You maintain texts and images in news_img or articles, and each object then points to its post or article.

## Set up

1. Add a post or article for each object in a news_img or articles section.
2. Choose this section in the [settings](settings.md) under **Object descriptions**.
3. Open an object with **Edit** and choose the matching post or article under **Description**.

A Reservations section is linked to exactly one section. For news_img the choice lists its active posts. For articles it lists the visible articles and the planned ones that appear later.

## What this changes

On the website the object name links to the post or article, in the occupancy plan, the week, the list and the calendar. In the post or article itself you can embed the [calendar of the object](droplet.md).

A planned article only gets the link once it appears. Until then the object list shows "orphaned".

## Orphaned descriptions

If a post or article is deactivated, deleted or moved to another section, the object list shows "orphaned". For articles this also applies to expired articles, to articles in an inactive group and to articles on a page visitors cannot open, such as a private page. The link goes away, everything else keeps working. Choose another description at the object, or **(none)**.

If you change the section in the settings, the existing links become orphaned. Link the objects again then.
