# Beschreibung aus news_img

Reservations verwaltet nur Name und Regeln eines Objekts. Texte und Bilder pflegen Sie in news_img, jedes Objekt verweist dann auf seinen Beitrag.

## Einrichten

1. Legen Sie für jedes Objekt in einem news_img-Abschnitt einen Beitrag an.
2. Wählen Sie in den [Einstellungen](settings.md) unter **Objektbeschreibungen aus news_img** diesen Abschnitt.
3. Öffnen Sie ein Objekt mit **Bearbeiten** und wählen Sie unter **Beschreibung** den passenden Beitrag.

Ein Reservations-Abschnitt ist genau einem news_img-Abschnitt zugeordnet. In der Auswahl stehen dessen aktive Beiträge.

## Was sich dadurch ändert

Der Objektname verlinkt auf der Website auf den Beitrag, im Belegungsplan, in der Woche, in der Liste und im Kalender. Im Beitrag selbst können Sie den [Kalender des Objekts](droplet.md) einbinden.

## Verwaiste Beschreibungen

Wird ein Beitrag deaktiviert, gelöscht oder in einen anderen Abschnitt verschoben, zeigt die Objektliste „verwaist“. Der Link entfällt, alles andere läuft weiter. Wählen Sie beim Objekt einen anderen Beitrag oder **(keine)**.
