# Add and edit objects

An object is anything that can be booked: a holiday flat, a room, a device. The object list is the first page you see when you open the section.

## Add an object

1. Enter a name below the list at **New object** and choose the [object type](types.md).
2. Leave **Active** on if the object should appear on the website.
3. Click **Save**. The object takes the defaults of its type.
4. Click **Edit** at the object in the list to set [booking rules](booking-rules.md) and [opening hours](opening-hours.md). These areas appear only once the object is saved.

## Order

The field **Order** decides the sequence of the objects in the list, on the website and in the request form. Smaller numbers come first. Objects with the same number stay in the sequence you added them.

With the single object display and no choice of your own, the section shows the first active object of this sequence.

## The object list

| Column | Meaning |
|---|---|
| Active | only active objects appear on the website and in the request form |
| Current bookings | running and future bookings with a blocking status, without open requests |
| Open requests | bookings with the status of the role "new request" |
| Description | with [news_img](news-img.md) only: the linked post |

**Bookings** takes you to the [bookings](bookings.md) of the object.

## Switch an object off for a while

Untick **Active**. The object disappears from the website, its bookings stay. For single periods, [blocked periods](blocked-times.md) are the better choice.

## Delete an object

Click **Delete** at the object in the list and confirm the question.

The link is missing as long as the object has running or future bookings with a blocking status, or open requests. This way no confirmed booking gets lost by accident. Cancel or delete these bookings first, or wait until they are over.

> [!WARNING]
> Past, cancelled and rejected bookings go with the object, including their requests and contact data, as do its opening hours. This cannot be undone. If you still need the occupancy, deactivate the object instead.

If the object was chosen for the single object display, the section then shows the first active object. A [droplet](droplet.md) with its ID stays empty.
