# Objekttypen

Objekttypen ordnen Ihre Objekte, etwa nach Ferienwohnung, Raum oder Gerät. Vor allem liefern sie Vorgabewerte für neue Objekte.

## Vorgabewerte

Ein Objekttyp kann alle [Buchungsregeln](booking-rules.md) vorgeben. Ein neues Objekt dieses Typs übernimmt die Werte beim Anlegen, danach lassen sie sich am Objekt ändern.

> [!NOTE]
> Änderungen am Objekttyp wirken nicht auf bestehende Objekte. Nur neue Objekte bekommen die neuen Werte.

[Öffnungszeiten](opening-hours.md) gehören zum einzelnen Objekt und lassen sich nicht vorgeben. Das Raster dagegen schon.

## Objekttyp anlegen

1. Klicken Sie oberhalb der Objektliste auf **Objekttypen**.
2. Tragen Sie unter **Neuer Objekttyp** einen Namen und die Reihenfolge ein.
3. Füllen Sie die Vorgabewerte aus, soweit Sie sie brauchen. Leer bedeutet: keine Grenze.
4. Klicken Sie auf **Speichern**.

## Objekttyp löschen

Sie können einen Objekttyp löschen, wenn kein Objekt ihn verwendet. Mindestens ein Objekttyp muss im Abschnitt bleiben.
