# Begriffe

Die wichtigsten Begriffe dieser Hilfe in alphabetischer Reihenfolge.

| Begriff | Bedeutung |
|---|---|
| Abschnitt | ein Reservations-Kalender auf einer WBCE-Seite, mit eigenen Objekten, Status und [Einstellungen](settings.md) |
| An- und Abreisezeit | Uhrzeiten im Buchungsmodus Tageweise, die Gäste im Anfrageformular und in den Mails sehen |
| Anfrage | Buchungswunsch über das Formular auf der Website. Sie wird als [Buchung](requests.md) gespeichert. |
| Blockieren | ein Status belegt den Zeitraum, andere Buchungen dürfen sich nicht damit überschneiden |
| Buchung | ein Zeitraum für ein Objekt, mit einem Status |
| Buchungsmodus | tageweise oder nach Zeitraum, gilt für den ganzen Abschnitt |
| Darstellung | mehrere Objekte oder ein Einzelobjekt |
| Droplet | Platzhalter in WBCE, hier für den [Kalender](droplet.md) an beliebiger Stelle |
| Höchstvorlauf | wie weit eine Anfrage höchstens in der Zukunft liegen darf |
| Kalenderfenster | die Monate, die Besucher erreichen können |
| Objekt | was gebucht wird: Wohnung, Raum, Gerät |
| Objekttyp | Gruppe von Objekten mit gemeinsamen Vorgabewerten |
| Puffer | Zeit, die zwischen zwei Buchungen frei bleibt |
| Raster | Takt, auf dem Beginn und Ende einer Anfrage liegen |
| Rolle | feste Aufgabe eines Status im Ablauf von Anfragen |
| Sperrzeit | Buchung mit blockierendem Status, etwa für Urlaub oder Wartung |
| Startansicht | die Ansicht, die Besucher zuerst sehen |
| Status | Zustand einer Buchung; bestimmt, ob sie blockiert und was Besucher sehen |
| Vorlauf | Mindestabstand zwischen Anfrage und Beginn |
| Wechseltag | Tag, an dem eine Buchung endet und die nächste beginnt |
