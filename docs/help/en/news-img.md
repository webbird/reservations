# Description from news_img

Reservations only manages the name and rules of an object. You maintain texts and images in news_img, and each object then points to its post.

## Set up

1. Add a post for each object in a news_img section.
2. Choose this section in the [settings](settings.md) under **Object descriptions from news_img**.
3. Open an object with **Edit** and choose the matching post under **Description**.

A Reservations section is linked to exactly one news_img section. The choice lists its active posts.

## What this changes

On the website the object name links to the post, in the occupancy plan, the week, the list and the calendar. In the post itself you can embed the [calendar of the object](droplet.md).

## Orphaned descriptions

If a post is deactivated, deleted or moved to another section, the object list shows "orphaned". The link goes away, everything else keeps working. Choose another post at the object, or **(none)**.
