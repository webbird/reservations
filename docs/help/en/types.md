# Object types

Object types sort your objects, for example into holiday flat, room or device. Above all, they provide defaults for new objects.

## Defaults

An object type can preset all [booking rules](booking-rules.md). A new object of this type takes the values when it is added; afterwards they can be changed at the object.

> [!NOTE]
> Changes to an object type do not affect existing objects. Only new objects get the new values.

[Opening hours](opening-hours.md) belong to the single object and cannot be preset. The grid can.

## Add an object type

1. Click **Object types** above the object list.
2. Enter a name and the order under **New object type**.
3. Fill in the defaults you need. Empty means no limit.
4. Click **Save**.

## Delete an object type

You can delete an object type if no object uses it. At least one object type must remain in the section.
